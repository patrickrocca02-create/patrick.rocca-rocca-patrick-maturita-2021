Eseguire in locale il back-end, ovvero il server Spring Boot,
e successivamente il front-end, ovver il client Angular.
Il database viene generato all'avvio e popolato con alcuni dati
di esempio (è necessario che MySQL Server sia in esecuzione).
Per utilizzare l'applicazione è necessatio registrarsi (inserire
dei dati casuali, anche la mail può essere inventata).
É necessaria la connessione ad Internet per l'utilizzo dei 
microservizi Lambda (dunque della sezione di calcolo matematico).

Il codice caricato per i diversi servizi su AWS Lambda è contenuto
in un jupyter notebook nella cartella "microservizi-lambda"

Per quanto riguarda l'input di espressioni matematiche, utilizzare
le classiche notazioni per le varie funzioni (cos(x), sin(x), ln(x) etc.).
e i vari operatori matematici noti (+,-,*,/,^ etc.). 
Attenzione: non sottintendere mai il '*' (ad esempio 3x dev'essere 
scritto: 3*x).

Per vedere un esempio di documento di teoria LaTeX, aprire il capitolo
sul decadimento radioattivo (il documento tex memorizzato nel database di
questo capitolo è inoltre disponibile nella cartella "Capitoli di teoria").
